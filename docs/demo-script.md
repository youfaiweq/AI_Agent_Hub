# v1.0 Demo Video Script

Target length: 5–7 minutes.

1. **0:00 — Product framing**: show the dashboard and explain that AgentHub combines enterprise knowledge, RAG, bounded Agents, memory, approval, observability, and evaluation.
2. **0:30 — Identity and knowledge**: register the demo user, open the seeded knowledge base, and show document status and ownership boundaries.
3. **1:30 — Retrieval-grounded Chat**: ask a question, show the answer and citations, then open Retrieval Debug to compare dense/hybrid/rerank evidence.
4. **2:30 — Agent runtime**: run the seeded Agent with Calculator or Knowledge Search, then open the run history and Tool Call records.
5. **3:30 — Human approval**: demonstrate a dangerous Tool in a test/demo configuration, show `waiting_approval`, reject once, then repeat with approve and resume.
6. **4:30 — Explicit memory**: extract a “remember” request, confirm it, edit the memory, and show search/delete ownership behavior.
7. **5:15 — Observability and Evaluation**: explain the fail-open Langfuse Adapter, show the trace event model, run the versioned evaluation dataset, and point out repeatable fingerprints.
8. **6:00 — Engineering close**: show the architecture/ER diagrams and summarize Docker, Alembic, tests, security audit, backup/recovery, and failure drills.

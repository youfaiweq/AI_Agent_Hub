# Resume Description

**AgentHub — Enterprise AI Knowledge and Task-Agent Platform**

- Built a FastAPI + Vue 3 modular monolith integrating PostgreSQL, Redis,
  Qdrant, MinIO, RAG ingestion/retrieval, LangGraph Agents, Tool Registry, and
  OpenAI-compatible providers.
- Implemented dense/sparse/hybrid retrieval, RRF fusion, reranking adapters,
  citation-grounded Chat, deterministic Evaluation metrics, and repeatable
  Dataset fingerprints.
- Designed bounded Agent execution with max steps, timeout/cancellation,
  structured Tool errors, durable Tool Call audit, explicit Memory, and
  Human-in-the-loop approval/resume for dangerous Tools.
- Added fail-open Langfuse OTLP observability across LLM, retrieval, rerank,
  Tool, Memory, and Agent boundaries; packaged the stack with Docker/Nginx,
  health checks, migrations, backup/recovery, and security checks.
